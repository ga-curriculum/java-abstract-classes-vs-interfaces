# ![abstract classes vs interfaces](./assets/abstract-classes-and-interfaces-header.png)

## About

By the end of this lesson, students will be proficient in writing abstract classes, defining interfaces in Java, and discerning the appropriate usage scenarios for abstract classes versus interfaces.

## Prerequisites

- None.

## Content

| Lesson | Time | Learning Objectives |
| ------ |:----------:|:------ |
| [Abstract Classes](./abstract-classes/README.md) | 25 min | Implement abstract classes in Java using the template method design pattern.  |
| [Interfaces](./interfaces/README.md) | 30 min | Practice implementing interfaces by creating classes that adhere to defined contracts.  |
| **Total content**  | 55 min |  |
